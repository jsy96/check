探测器与文件格式

整线由 N 片 CCD 垂轨拼接；文件含 1 个虚拟片 + N×B 个物理片块
波段数 bandCount B
多光谱波段个数；各波段沿轨错开（共线排列）
每波段 CCD 片数 sensorCount N
同一波段的 N 片 CCD 垂轨并排拼成一条长线阵
每片探元数 width W
单片 CCD 的探元个数（文件中的 width）
拼接重叠像元数 ovl
相邻 CCD 垂轨搭接像元数，0 = 无缝；taijing304 实例为 25
多项式阶数 nCamPoly
lookAngle 多项式阶数，每行系数个数 = 阶数+1（示例文件为 5）
文件块顺序
默认片优先，与需求说明及 taijing304_MSS.coef 实测块序一致
虚拟片 X 取法
交错排列下两种取法不同：全局最小 = 最小基偏移 + 较小分量；片内最大→片间最小 = 最大基偏移 + 较小分量

轨道 / 光学

恒等式 GSD = p·H/f（星下点平面近似）；p、f、H、GSD 任留空一项自动推导
焦距 f
主距；生成系数必需（或可由 GSD·p 反推）
探元尺寸 p
垂轨像元尺寸；lookAngleY 斜率 = −p/f
轨道高度 H
用于 GSD / 幅宽 / 波段沿轨基线计算
地面分辨率 GSD
星下点平面近似 GSD = p·H/f
地球半径 R
预填 6371 km；供地平线角校验

CCD 排列（沿轨方向 X）

lookAngleX 为沿轨方向；(tanX, tanY, 1) 是相机坐标系探元矢量
排列方式
各波段均有沿轨基偏移（下方输入）；交错排列再叠加奇/偶片沿轨交错分量

      格式与口径说明（点击展开）
      

        
文件头：nCamPoly 多项式阶数（每行系数个数 = 阶数+1）；bandCount 波段数 B；sensorCount 每波段片数 N；angleBiasRoll/Pitch/Yaw 与 angleBiasR（3×3 行优先）为本工具固定输出的零偏置 / 单位阵。

        
探元块：共 1 + N×B 块，每块三行 width= 探元数、lookAngleX: c₀ … cₖ、lookAngleY: c₀ … cₖ。lookAngleX 沿轨、lookAngleY 垂轨，系数得到的是视角正切值：多项式取值 (tanX, tanY) 使 (tanX, tanY, 1) 为相机坐标系探元视线矢量；自变量为 0 基探元序号 j = 0…W−1。

        
几何模型（已用 taijing304_MSS.coef 数值复现验证）：像元角步长 s = p/f；整线关于主点垂轨居中，半跨度 = 虚拟片宽×s/2；第 i 片 lookAngleY 常数项 = 半跨度 − (i−1)·(W−ovl)·s，一次项 = −s；lookAngleX 常数项：共线排列 = tan(波段沿轨离轴角)，交错排列 = 波段基偏移 + 奇/偶片交错分量（各波段均有基偏移，两种排列通用）。

        
坐标约定：x 沿轨向下为正、y 垂轨向左为正；各片探元 0 在左端（tanY 最大端），探元序号增大 tanY 减小。

        
虚拟片（第 0 块）：沿轨方向排在最前面（图上最上方）的那组 CCD 拼接得到的虚拟 CCD，width = N·W − (N−1)·ovl，lookAngleY 覆盖整条拼接线。lookAngleX 默认取全局最小（与 taijing304_MSS.coef 实例一致）：共线排列 = tanX 最小的波段，交错排列 = 最小基偏移 + 较小交错分量；备选「片内最大→片间最小」= 共线最大基偏移 / 交错最大基偏移 + 较小分量。

        
GSD / 幅宽：星下点平面近似 GSD = p·H/f，幅宽 = 虚拟片宽 × GSD；边缘离轴角 = atan(半跨度)，超过地平线角 arcsin(R/(R+H)) 报警；波段间沿轨地面基线 = H·ΔtanX（配准用）。

        
块顺序：默认片优先——第 1 片 CCD 的第 1…B 波段，再第 2 片……（与需求说明及 taijing304_MSS.coef 实测块序一致）；如需"第 1 波段的 N 片 → 第 2 波段的 N 片"可在左栏切到波段优先。

        
字节格式：ASCII、CRLF 换行、无 BOM、末尾单个换行；系数 C 风格 %.18e（指数至少两位，如 1.2e-2 → e-02）；angleBias 三行用 %.18f 定点；width= 后有一个空格，lookAngleX: 后有一个空格。
