# 509simu · 面阵相机卫星摆扫参数一致性校验

对摆扫（whisk-broom）成像模式的面阵相机卫星做粗略几何/时序计算：输入焦距、轨道、探测器、帧频、摆扫等参数，工具自动推导缺失量、并对所有冗余给出方式做**矛盾检测**（含漏扫判据）。

**版本**：v1.0.260820-1（显示在页面右上角）

## 文件

| 文件 | 说明 |
|---|---|
| `whiskbroom_check.html` | 单文件网页工具，双击用浏览器打开即用，无任何依赖 |
| `test_core.cjs` | Node 自测脚本：从 HTML 抽出核心计算块，验证推导链与校验触发 |

## 使用

1. 双击 `whiskbroom_check.html` 打开；
2. 左栏按组输入参数（全局/轨道、沿迹、穿迹），**留空的参数自动由公式推导**（推导值显示在输入框下方）；
3. 右栏实时输出：推导汇总、恒等式一致性校验、物理约束、参考量；矛盾项红色标出并给出偏差百分比；
4. 容差（默认 2%）可调；输入自动存入 localStorage；「导出参数 JSON」可存档当前输入+推导结果。

## 参数与恒等式

内部统一 SI 单位（m、rad、s、Hz、m/s、m³/s²），输入框可切换单位。

**全局/轨道**：R、μ（预填默认）、H ↔ a = R+H ↔ a = μ/v²、v_sat = √(μ/a)、星下点地速 v_g = v_sat·R/a、焦距 f（可由 f = H·L/D∥ 或 f = H·W/D⊥ 反推）。

**沿迹（飞行方向）**：N·p∥ = L = f·Ω∥ = f·D∥/H，D∥ = H·L/f = H·Ω∥；**卫星飞行时长 = 摆扫周期 T**（两次相邻摆扫开始时刻之差，留空按连续摆扫 T = N_f·t_f 推导）。

**穿迹（摆扫方向）**：M·p⊥ = W = f·Ω⊥ = f·D⊥/H，D⊥ = H·W/f；帧频 F = 1/t_f；**45° 扫描镜 2:1**：视线角速度 = 2×镜转速，帧间角 Δθ = 2·ω镜·t_f = Θ/N_f；帧间步进 s = H·Δθ；总摆扫角 Θ = N_f×Δθ；球面换算（视线角 θ → 地心角 φ，斜距 t = a·cosθ − √(R² − a²sin²θ)，φ = atan2(t·sinθ, a − t·cosθ)）得 φ总 → 幅宽 SW = R·φ总（星下点居中：φ总 = 2φ(Θ/2)；从星下点开始：φ总 = φ(Θ)，页面可选模式）。

## 矛盾检测

- **恒等式互检**：同一量有两种以上给出方式时自动比对（如帧频 vs 帧间时长、L vs N×p、Θ vs N_f×Δθ、SW vs R·φ……），相对偏差超容差报红；
- **物理约束（不等式）**：
  - 条带间不漏扫：`v_g·T ≤ D∥`（摆扫周期内卫星飞行距离不得超过沿迹覆盖，否则两次摆扫之间沿迹漏缝）——核心判据；
  - 帧间不漏扫：`s ≤ D⊥`；
  - 时序：`T ≥ N_f·t_f`（摆扫未结束不得开始下一程；大于则为空闲/回扫提示）；
  - 视场：摆扫边缘视线角 ≤ 地平线角 arcsin(R/a)；
  - 摆扫边缘帧间漏扫复核（球面几何，斜距增大导致覆盖拉稀）。

覆盖 6 个用例：全冗余零矛盾、条带漏扫触发、骨干参数推导链、故意错误值的互检报警、由速度反推轨道、帧间漏扫触发。

## 口径约定（与需求确认一致）

- 摆扫角速度参数为**扫描镜转速**，视线角速度 = 2×（45° 镜）；
- 总摆扫角 Θ = N_f × Δθ（帧间角 × 总帧数）；
- 沿迹"卫星飞行时长"= 摆扫周期 = 两次相邻摆扫开始时刻之差；
- 除地心角/幅宽用球面换算外，其余为星下点平面近似（粗略计算口径）。
