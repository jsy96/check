两个单文件网页工具（双击用浏览器打开即用，无任何依赖）+ Node 自测脚本：

## 工具一：面阵相机卫星摆扫 · 参数一致性校验（wiskbroom.html）

对摆扫（whisk-broom）成像模式的面阵相机卫星做粗略几何/时序计算：输入焦距、轨道、探测器、帧频、摆扫等参数，工具自动推导缺失量、并对所有冗余给出方式做**矛盾检测**（含漏扫判据）。

**使用**：左栏按组输入（全局/轨道、沿迹、穿迹），留空的参数自动由公式推导（推导值显示在输入框下方）；右栏实时输出推导汇总、恒等式一致性校验、物理约束（条带/帧间漏扫、时序、地平线）、参考量。容差（默认 2%）可调；输入自动保存到浏览器 localStorage；「保存/读取参数 TXT」为参数存档（UTF-8 带 BOM，行格式 `参数ID = 数值 [单位]`，`#` 后为注释）。

**口径**：内部统一 SI 单位；45° 扫描镜 2:1（视线角速度 = 2×镜转速）；总摆扫角 Θ = N_f×Δθ；漏扫判据 `v_g·T ≤ D∥`；地心角/幅宽用球面换算，其余为星下点平面近似。公式细节见页面底部「公式与口径说明」。

**自测**：`node test_core.cjs`（7 个用例：推导链闭环、漏扫触发、矛盾报警、TXT 往返等）。

## 工具二：线阵推扫相机参数计算（pushbroom.html）

输入线阵推扫相机参数，实时计算并**生成/保存 `taijing304_MSS.coef` 格式的安装系数文件**到本地。

### 输入参数

- **探测器/格式**：波段数 B、每波段 CCD 片数 N、每片探元数 W、拼接重叠像元数 ovl（默认 0）、多项式阶数 nCamPoly（默认 5 → 每行 6 个系数）、文件块顺序（片优先/波段优先）、虚拟片 X 取法、输出文件名；
- **轨道/光学**：焦距 f、探元尺寸 p、轨道高度 H、GSD——恒等式 `GSD = p·H/f`（星下点平面近似），任留空一项自动推导；地球半径 R（预填 6371 km，供地平线角校验）；
- **CCD 排列（沿轨方向 X）**：
  - **共线排列**：各波段整排在沿轨方向错开——按"焦面距离 d（tanX = d/f）"或"离轴角 α（tanX = tanα）"输入（可切换、自动换算），支持 d₁+Δd 等间距快速填充 + 每波段单独修改；
  - **交错排列**：奇数片、偶数片各一个沿轨位置/离轴角，各波段共用。

### 输出与校验

- 右栏实时 **.coef 文件预览**（即文件字节内容）与「保存 .coef 文件」按钮；
- 推导汇总：像元角步长 p/f、虚拟片宽、全视场角、幅宽（= 虚拟片宽×GSD）、边缘离轴角/边缘穿轨采样等；
- 一致性校验：GSD 恒等式（超容差报红）、ovl 范围、奇偶错开/波段错开、边缘离轴角 ≤ 地平线角等；
- 布置明细：各波段 tanX/离轴角/沿轨地面基线（配准用），各片 det0/末探元 tanY 与垂轨角范围；
- 输入自动保存 localStorage；「保存/读取参数 TXT」参数存档（同工具一风格，元参数行 `layout / offsetMode / blockOrder / tolerance / filename`，`dbN` 为第 N 波段偏移）。

### .coef 文件格式（与 taijing304_MSS.coef 一致）

ASCII、**CRLF 换行、无 BOM**、末尾单个换行；系数 C 风格 `%.18e`（指数至少两位，如 `e-02`）；`angleBias*` 三行 `%.18f` 定点。

```
nCamPoly=5                 多项式阶数（每行系数个数 = 阶数+1）
bandCount=4                波段数 B
sensorCount=3              每波段 CCD 片数 N
angleBiasRoll=0.000...     零偏置（%.18f）
angleBiasPitch / angleBiasYaw 同上
angleBiasR:1.0e+00 ...     3×3 行优先单位阵（9 个 %.18e，冒号后无空格）
随后 1 + N×B 个探元块，每块 3 行：
width= 9166                探元数（"width=" 后有一个空格）
lookAngleX: c0 c1 …        沿轨方向 tan 多项式（自变量为 0 基探元序号 j）
lookAngleY: c0 c1 …        垂轨方向 tan 多项式（"lookAngleY:" 后有一个空格）
```

- 系数含义：多项式取值 (tanX, tanY) 使 **`(tanX, tanY, 1)` 为相机坐标系探元视线矢量**；
- **块顺序（片优先）**：虚拟片 → 第 1 片的第 1…B 波段 → 第 2 片的第 1…B 波段 → …（与需求说明及实例文件一致；也可切换为波段优先）；
- **虚拟片（第 0 块）**：沿轨最前那组 CCD 拼接得到的虚拟 CCD，width = N·W−(N−1)·ovl；lookAngleX 默认按「**每片 CCD 各波段取最大 → 再各片取最小**」（共线排列各片均含全部波段，即 tanX 最大的波段；交错排列即奇/偶片中较小者），可切换为「全局最小」——taijing304_MSS.coef 实例文件的虚拟块即全局最小口径（两者在交错排列下结果相同）；
- **几何模型**（已用实例文件数值复现，最大相对偏差 1.4e-16）：像元角步长 s = p/f；整线关于主点垂轨居中，半跨度 = 虚拟片宽×s/2；第 i 片 lookAngleY 常数项 = 半跨度 − (i−1)·(W−ovl)·s、一次项 = −s；lookAngleX 常数项 = tan(波段/奇偶片沿轨离轴角)、高次项为 0；
- 实例文件参数（反推）：p/f = 3.995861429234007983e-06、ovl = 25 像元、虚拟片宽 9166。
