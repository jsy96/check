      格式与口径说明（点击展开）
      

        
与线阵（pushbroom）文件的差异：首行多 Type=Frame；多项式头为 CamPoly=3（线阵是 nCamPoly=n 一元 n 次）；每块多一行 height=；lookAngle 为二元 3 次多项式（10 项），项序 1, x, y, x², xy, y², x³, x²y, xy², y³；系数 %.18e 以两个空格分隔（taijing 线阵实例为单空格）；angleBiasR 为 %.18f 定点、3×3 行组间两空格（gf4b-VIS 实例口径；实例中 [0][2] 为 −0 是标定数据噪声，本工具生成 +0）。

        
探元块：共 1 + N×B 块，每块四行 width= 探元数、height= 探元数、lookAngleX: c₀ … c₉、lookAngleY: c₀ … c₉。自变量为 0 基探元序号 x = 0…W−1（width 方向）、y = 0…H−1（height 方向）；多项式取值 (tanX, tanY) 使 (tanX, tanY, 1) 为相机坐标系探元视线矢量。方向口径：探元序号 x/width 向右为正、y/height 向下为正（数据/图像口径）；对应视线方向 lookAngleX 向下为正、lookAngleY 向左为正（焦面示意口径）——两口径相差 90°，由正斜率 c₁ = c₂ = p/f 关联（width 序号增大 → tanX 增大 → 焦面图中向下；height 序号增大 → tanY 增大 → 向左）。

        
几何模型（已用 gf4b-VIS.coef 实例数值验证）：理想模型下第 i 片 lookAngleX 系数 c₀ = x₀ᵢ/f（原点切角）、c₁ = p/f，其余 0；lookAngleY 系数 c₀ = y₀ᵢ/f、c₂ = p/f，其余 0（gf4b 实例实测：各片 c₁/c₂ 均为 5.517241379310344e-07、相互偏差 < 1e-21，高次项为 e-2x 量级标定噪声，理想生成输出精确 0）。

        
虚拟整帧（第 0 块）：全焦面外接框——width = ⌈(max x₀ − min x₀)/p⌉ + W，height 同理；lookAngleX c₀ = min x₀/f、lookAngleY c₀ = min y₀/f（gf4b 实例：虚拟块两轴 c₀ 与各片最小 c₀ 严格相等；其实例尺寸 22504 = 2×12288−2072、22438 = 2×12288−2138，为 2×2 拼接设计搭接约 2072×2138 像元，实测片位姿偏差使外接框（约 22539×22456）比设计格网大一二十至三十五像元，属正常）。

        
原点文件：kjg.txt 格式——首行 ccd	x	y 表头（可省略），随后每行 片号 x y，TAB/空格/逗号/分号分隔；# 与 // 为注释；缺片号列按行序自动编号；片顺序即文件行序，sensorCount = 行数。

        
搭接 / 间隙：单片物理 footprint = W·p × H·p；两片 |Δx₀| < W·p 且 |Δy₀| < H·p 即存在 2D 搭接（拼接设计常态，如 gf4b 设计搭接约 2072×2138 像元）；x、y 各向做投影区间并集检查，存在间隙即提示（投影全覆盖不排除棋盘形 2D 空洞）。

        
GSD / 幅宽 / 视场：星下点平面近似 GSD = p·H/f；幅宽 × 幅高 = 虚拟整帧 Vw×Vh × GSD；X/Y 向全视场角 = atan(tan 末探元) − atan(tan 首探元)，对角视场角 = 两对角角点视线矢量夹角；边缘离轴角 = atan(√(tanX²+tanY²)) 取最远角点，超过地平线角 arcsin(R/(R+H)) 报警。

        
字节格式：ASCII、CRLF 换行、无 BOM、末尾单个换行；系数 C 风格 %.18e（指数至少两位，如 1.2e-2 → e-02）双空格分隔；angleBias 三行 %.18f 定点；width= / height= 后各有一个空格，lookAngleX: 后有一个空格。
